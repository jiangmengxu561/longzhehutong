线路 & 调度 · 详细操作流程

本页讲透「我的订单」背后，线路（销售）和调度各自拿到一单后，一步一步该做什么、每个按钮干什么、碰到异常怎么办。这是给这两个角色新员工的主教材。

先懂

一单在两个角色手里怎么接力

客户下单→ 线路：看单·核对·确认→ 调度：配车·派司机·跟运输→ 司机端：装货·运输·送达→ 完成（扣抽佣 / 结算）

关键分界线：线路负责“把单接下来并确认清楚”；调度负责“把车和司机派出去、跟到货、处理好收款和到达”。线路确认后订单才进入调度的列表。

线路（销售）调度
能看到什么自己这家加盟商范围的单（配车/专车/小票快运都有）。只看到「找车类型=配车」且「线路已确认」的单。
核心动作核对 + 确认订单（配车确定订单 / 填金额） + 打印 + 看轨迹。指派车辆司机 + 填成本 + 跟踪 + 展示收款码/确认收款 + 专线到达 + 信息费打款。
不能做什么不能配车派司机，不能看下级/别家的单。不能看线路还没确认的单，不能看专车/小票快运单，不能看下级/别家。

说明：按钮会随订单状态变化。下面按“配车单”“专车/小票快运单”“异常单”三种情况讲。
Step1

看有没有新单

  1. 左侧点「我的订单」。
  2. 把右上角「开通提醒」打开（每台电脑记住），有新单会语音 + 弹窗。
  3. 新单一般排前面，看支付状态 / 物流状态判断是不是待处理。
  4. 数量多就用上方搜索/筛选（按订单号、时间、找车类型、状态）。
Step2

核对这单信息（重要，别急）

点「查看订单信息」逐项核对，错一项后面全乱：

地址装货地 → 卸货地，联系人和电话是否完整。地址错要客户改，或你联系确认。
货物品名、重量、体积、车型要求、包装。不对会派错车。
找车类型配车 / 专车 / 小票快运——决定你点哪个确认按钮。
金额总运费 / 信息费+不可退回定金。价格没谈好先别确认。
时效最早/最晚装货、预计到货时间。
支付方式寄付 / 到付 / 月结。月结特别注意后面要扣钱。
信息不全先别确认：补齐或让客户改完再确认，避免后面返工。
Step3

确认订单（分两种情况）

情况 A：找车类型 = 配车
  1. 看该单「找车类型=配车」且尚未确认。
  2. 点操作列「配车确定订单」。
  3. 弹窗「确定要确认配车订单吗？」→ 点确定。
  4. 确认后订单进入调度的列表（由调度去安排车辆/司机）。你这一步就完成了。
情况 B：找车类型 = 专车 / 小票快运
  1. 点「专车/小票快运确定订单」。
  2. 系统弹框让你填订单金额（元）——填你们谈好的总运费。
  3. 点确定，订单标记为「已出价」。
金额填错怎么办：用「重新报价」再填一次（仅线路、未收货前可用）。
Step4

确认后的日常：打印 / 看轨迹 / 改费

打印「托运单模板」「签收单模板」：给司机/客户纸质单证。
查看物流轨迹「更多 → 查看物流轨迹」：看装货、运输、到达各环节。
修改订单总运费「更多」里，金额谈变了改这个。
修改订单成本 / 线路成本「更多」里，填这单的干线/路线成本，用于算利润。
上传装货现场照片「更多」里，装货后拍照留存，方便对账和追责。
查看下单情况看这个客户下过哪些单。
Step5

异常单怎么处理（驳回 / 取消 / 退款）

驳回客户信息不对（地址/数量/重量/车型/金额）→ 点「驳回」，选只允许客户修改哪一项 + 填原因。客户改完重新提交。
取消客户不要了 → 看是否已派车。已派车要先把司机订单取消，避免损失。
退款已收款要退 → 用「退款」，确认金额和方式。
注意：驳回后（pay_status=8）订单会锁住大部分操作，只能「查看订单信息 / 查看物流轨迹」，先让客户改好再走。
Step6

这单到你手里就算结束了？

  1. 「配车」单：你确认后交给调度，你的职责就到这。
  2. 「专车/小票快运」单：你确认金额后，后续由调度/专线处理，你偶尔跟踪即可。
  3. 等订单完成，你可以在「订单管理」看利润；日常主要精力放在开发客户、接单、确认、报价上。
🚚 调度详细操作流程
Reference

你的工作界面（真实截图）

1顶部统计（和线路一致）
2操作：查看订单信息 / 展示收款码 / 打印 / 更多
3更多：修改订单成本 / 填写杂费 / 上传图片 等
说明：你列表里只会出现「找车类型=配车」且「线路已确认」的单；专车/快运、未确认的你不会看到。
Step1

看有没有待派车的单

  1. 左侧「我的订单」，打开「开通提醒」。
  2. 只看「找车类型=配车」且「线路已确认、待指派」的单。
  3. 重点看：地址、重量/体积、车型、时效、是否月结——这决定派什么车、派几个司机。
Step2

指派车辆和司机（核心）

  1. 点「查看订单信息」查看详情。
  2. 根据货重/体积/车型，选合适的车辆和司机（取货司机=装货端，送货司机=卸货端，按需指派，用司机端接单）。
  3. 填司机运费/成本。
  4. 指派后，司机端就收到任务，开始取货、运输。
注意：选司机的手机号/车辆信息必须准确；司机没注册司机端就让他先注册，否则接不到单。
Step3

填成本、跟进运输

修改订单成本「更多」里，填干线费/司机费等，用于算利润和扣费用。
填写杂费「更多」里，回单费/拆包费/定金等额外费用。
上传相关图片「更多」里，装货/运输/签收照片，便于追责和结算。
查看物流轨迹「更多」里，实时看装货、运输、到达。
改派司机司机临时换/联系不上 → 先「取消该司机订单」，再重新指派（以实际按钮为准）。
Step4

收货与收款

专线确认到达专线运单到了 → 点「专线确认到达」，系统问“是否已扣专线费”，按实际回答（影响从调度备用金扣钱）。
信息费确认打款有信息费/额外费用要付给司机/信息部 → 点「信息费确认打款」，看好金额再打，备注清楚。
展示收款码要收客户钱 → 点「展示收款码」，选收款方式（二维码/其它），把收款方式展示给客户。
确认已收款客户已付款 → 在收款方式弹窗点「确定」；未收到钱千万别确认。
标记为送货这单需要送货 → 点「送货」。月结送货完成会从调度备用金扣全部订单运费。
收款纪律：确认已收款只在你确认钱已实际到账后再点，否则容易出坏账。
Step5

订单完成 & 对账

  1. 司机端确认完成，或你后台「确认收货/专车到达」，订单进入完成。
  2. 完成后系统会自动扣抽佣（按总运费×比例），月结送货还会扣调度备用金（干线费+送货费+利润）。
  3. 在「财务 → 流水/备用金」看扣款，和「订单管理」里利润对一下。
  4. 发现多扣/漏扣，第一时间找管理员。
Step6

备用金（你账号的钱）

  • 调度账号有自己的「调度/线路备用金」，可在财务里查看、充值自己账号。
  • 用途：月结送货、信息费打款等从这扣。余额不足会操作失败。
  • 要加钱：找管理员（老板）给你充。你只看得到自己的，看不到别人。
❓ 线路 & 调度 常见问题
FAQ

对不上情况时先看这里

我看到别人看不到的单？别慌，是你这家加盟商范围（绑定会员/区域）内的单。不是这家的就不该出现。
我看到“配车确定订单”但点不了？可能不是配车单、或已确认过、或你不是线路角色。核对找车类型。
调度看不到这单？订单可能还没被线路确认（还是配车但未确认），或不是配车类型，或不是你这家加盟商的。
订单被驳回了？信息要改。看原因 → 让客户改对应项 → 重新提交。驳回后大部分按钮锁定。
扣了我备用金？多为月结送货完成扣费，或信息费打款。看流水备注确认。
账号看不到某些菜单？角色组权限没勾。找管理员在「角色组」勾选（只给必要的业务菜单）。
