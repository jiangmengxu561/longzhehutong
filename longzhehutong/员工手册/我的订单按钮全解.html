「我的订单」按钮全解（线路 / 调度）

把「我的订单」里你能看到的所有按钮逐个讲清楚。按钮分三处出现：① 操作列直接显示、② 「打印」下拉、③ 「更多」下拉。同一单可用的按钮会随找车类型（配车/专车/小票快运）和订单状态变化——某个按钮没出现不是丢了，是该状态不该显示。

◆ 先看 ◆ 两者都能用的 ■ 线路专属 ■ 调度专属 ◆ 「更多」里每一项
🧭 先说清楚：按钮是怎么分出来的

标签说明：

顶部按钮 = 点单直接在「操作」列看到；「打印」 = 点「打印」按钮展开；「更多」 = 点「更多」按钮展开。

两者都能线路调度 = 这个按钮平时是哪个角色在用。

判断一个单（正常流程）：

  1. 看「找车类型」：配车 → 线路确认后交调度；专车/小票快运 → 线路填金额。
  2. 看「支付状态 / 物流状态」：待付款 / 待处理 → 要先处理；已完成 / 已收货 → 操作基本锁住。
  3. 看「是否已驳回」（已驳回）→ 只能看信息/轨迹，其他按钮全隐藏。
🧰 线路、调度都能用的按钮（操作列直接显示）
取消（取消订单）两者都能顶部

出现：未完成、未取消的订单。

整单作废。客户不要了才点。

注意：如果已经派了车/司机，先取消司机/专线订单，不然会有损失或纠纷。

驳回（让客户改信息）两者都能顶部

出现：未收货、未驳回的订单。

订单信息里客户填错了（地址/数量/重量/尺寸/货物类型/车型/总运费等），点「驳回」后可指定“只允许客户修改哪一项”并填驳回原因，客户改完重新提交。

注意：驳回后（已驳回）订单会锁住大部分操作，只能「查看订单信息 / 查看物流轨迹」。

查看订单信息两者都能顶部

看这单的完整详情（地址、货物、金额、车型、时效、司机等）。线路看它核对，调度看它派车派司机。

用法：几乎每单第一步都先点它把关。

送货（标记为送货 / 取消送货）两者都能顶部

「送货」：还没送货、未收货时显示；「取消送货」：已经标记送货时才显示。

标记这单需要送货。注意提示：月结货物送货完成后，会从调度备用金扣掉全部订单运费；非月结则只按规则扣。

注意：确认“月结送货”会动到备用金，确定已在负责再点。

打印（下拉：托运单模板 / 签收单模板）两者都能「打印」

打印纸质单证：托运单模板（针式底图，随车）、签收单模板（和前端签收单一致，给收货方签字）。

用法：安排车前/送达时打印给司机和客户。

查看物流轨迹两者都能「更多」

看这单的物流轨迹：装货、运输、到达、派送等节点。跟进度、处理异常都用它。

上传图片 / 上传装货现场照片两者都能「更多」

上传这单的照片：装货现场、货物、签收、运单等，留证据、方便对账和追责。

用法：装货后、送达后拍照上传。

🎯 线路（销售）专属按钮
配车确定订单线路顶部

出现：找车类型=配车、你是线路、还没确认过。

确认这单是配车单，确认后订单交到调度去安排车辆和司机。

注意：确认前一定要核对地址/货/金额，确认后就轮到调度了。

专车 / 小票快运确定订单线路顶部

出现：找车类型=专车或小票快运、你是线路、未确认。

确认时弹窗让你输入订单金额（总运费），填好确定后订单标记为「已出价」。

重新报价线路「更多」

出现：你是线路、未收货、已确认过。

已确认但金额谈变了 → 填新金额重新确认。

填写订单信息（专车/小票快运信息）线路「更多」

出现：你是线路，按订单类型（专车/小票快运）显示。

补充专车/快运的车辆、司机、价格等字段（司机姓名/电话/价格必填），把承运信息填完整。

查看路线线路「更多」

出现：你是线路，配车单。

看这条线路/路线的成本与规划，用于判断这单成本。

修改线路成本线路「更多」

出现：你是线路、找车类型=配车、物流状态 < 4（未进入运输）。

填/改这单的线路成本（干线成本），用于算利润。可填备注说明原因。

注意：专车/小票快运不显示；已运输后（状态≥4）也不显示，要改找管理员。

填写取货司机 / 司机成本线路「更多」

出现：你是线路（调度不显示），按订单类型/状态出现司机相关表单。

填取货司机的姓名/电话/价格（部分会带货运平台税点）、或司机成本/单价/其他价等明细。

🚚 调度专属按钮
展示收款码 / 展示收款账号调度顶部

出现：你是调度。

要收客户钱时，点它弹出收款方式列表，选收款方式（二维码 / 其它），把收款方式给客户。

确认已收款（收款流程里）调度顶部

在「展示收款码 → 选收款方式 → 确定」这步触发。点确定前系统会问“确认款项已经实际到账”，选「确认已收款」。

纪律：只有钱确实到账才确认，否则会出坏账。

专线确认到达调度「更多」

出现：你是调度、已完成专线前（专线状态≠2）。

专线运单送到了 → 点它，系统问“是否已扣专线费？”：是=已扣，走备用金扣干线费；否=沿用原扣费逻辑（填送货司机时扣）。

信息费确认打款调度「更多」

出现：你是调度、该单有信息费/额外费用且未打款。

给信息部/司机付信息费、回单费、拆包费、定金等。点开先看金额和备用金余额，再确认打款。

注意：余额不够会失败；先看金额对不对。

📦 「更多」下拉里还可能出现的（线路/调度按状态显示）

这些按订单类型和状态出现，主要和成本、费用、取消有关：

按钮干什么
修改订单总运费改这单的总运费（线路常用）。
修改订单成本填整单成本，用于算利润。
填写杂费回单费、拆包费、定金等额外费用（调度多）。
填写回单寄回单号回单要寄回时，填快递名+单号（仅回单方式=寄回时显示）。
取消司机订单撤掉某个司机（取货/送货）的单，先确认再改派。
取消专线订单撤掉专线承运单。
下载文件下载该单相关文件/单据。

记不住没关系：用不到就看灰色的、或一个都别乱点。做之前先想：这单现在到了哪一步（已下单/派车/运输/到达/收货），只点和那一步对应的按钮。

安全底线：① 已驳回的订单只能看，别乱点。② 金额/成本别随便改，改了要能说明白。③ “确认已收款”“信息费打款”“月结送货”都动钱，确认清楚再点。
