# 线路（销售）操作手册

> 适用对象：加盟商旗下的**线路 / 销售**员工，用「线路账号」登录。
> 后台地址：`https://lzwl.longzhehutong.cn/KdfitrTRTTBYLWTJ.php`

---

## 一、你是干什么的

你是**前线接单**的人。客户下单后，你第一个看到订单，你负责：

1. 看<b>新单</b>（有提醒）。
2. 核对<b>订单信息</b>。
3. <b>确认订单</b>（配车确定订单 / 填金额）。
4. 确认后<b>交给调度</b>去配车派司机。

一句话：**你负责“把单接下来、确认清楚”，剩下派车派司机是调度的事。**

你可以看到<b>你这家加盟商范围</b>的订单（绑定会员的 + 区域内普通用户的）。**看不到**下级加盟商和别家的单。

---

## 二、进入「我的订单」

1. 登录后台，进「<b>我的订单</b>」。
2. 打开右上角「<b>开通提醒</b>」（每台电脑记住），有新单会<b>语音 + 弹窗</b>。
3. 新单一般排前面，可看状态判断是否待处理；单多就用搜索/筛选（订单号、时间、找车类型、状态）。

顶部统计看一眼：<b>总收入 / 总支出 / 利润</b>、<b>总吨数 / 总方数 / 总单量</b>。

---

## 三、核对订单信息（重要，别急）

点「<b>查看订单信息</b>」逐项确认，错一项后面全乱：

| 项 | 看什么 |
|----|--------|
| 地址 | 装货地 → 卸货地，联系人和电话是否完整 |
| 货物 | 品名、重量、体积、车型要求、包装 |
| 找车类型 | 配车 / 专车 / 小票快运（决定哪个确认按钮） |
| 金额 | 总运费、信息费+不可退回定金 |
| 时效 | 最早/最晚装货、预计到货时间 |
| 支付方式 | 寄付 / 到付 / 月结（月结注意扣钱） |

> 信息不全先别确认：让客户改，或联系补齐，避免返工。

---

## 四、确认订单（分两种情况）

### 情况 A：找车类型 = 配车

1. 点操作列「<b>配车确定订单</b>」。
2. 弹窗“确定要确认配车订单吗？”→ 点<b>确定</b>。
3. 确认后订单<b>进入调度的列表</b>（调度安排车和司机）。

> 此按钮只对<b>找车类型=配车</b>、<b>线路角色</b>、<b>未确认</b>的单显示。

### 情况 B：找车类型 = 专车 / 小票快运

1. 点「<b>专车/小票快运确定订单</b>」。
2. 弹窗<b>输入订单金额（元）</b>——填谈好的<b>总运费</b>。
3. 点确定，订单标记为「<b>已出价</b>」。

> 金额填错了？用「<b>重新报价</b>」再填（未收货前可用）。

| 操作 | 在哪 | 干嘛 |
|------|------|------|
| 打印 | 操作列「打印」 | 出「托运单 / 签收单」 |
| 查看物流轨迹 | 「更多」 | 看装货/运输/到达 |
| 修改订单总运费 | 「更多」 | 金额变了改这个 |
| 修改订单/线路成本 | 「更多」 | 填成本算利润 |
| 上传装货现场照片 | 「更多」 | 装货后拍照留证 |
| 查看下单情况 | 会员行操作 | 看这个客户历史订单 |

## 六、异常单处理

| 情况 | 怎么做 |
|------|--------|
| 驳回 | 信息不对 → 点「<b>驳回</b>」，选“只允许客户改哪一项”+ 填原因，客户改完重新提交。驳回后（已驳回）大部分按钮会锁住，只能查看信息/轨迹。 |
| 取消 | 客户不要了 → 先确认是否已派车；已派车先把司机订单取消，避免损失。 |
| 退款 | 已收款要退 → 用「<b>退款</b>」，确认金额和方式。 |

---

## 七、订单状态（遇到看得懂）

| 状态 | 含义 | 你做什么 |
|------|------|---------|
| 待付款 | 客户没付钱 | 确认线下是否已收，或催付 |
| 待下单 | 填了没下单 | 联系客户确认 |
| 进行中 | 运输中 | 跟进度 |
| 已出价 / 确认价格 | 你已确认金额 | 交调度 / 安排专车 |
| 已完成 | 送达确认 | 对账 |
| 驳回 | 后台退回 | 看原因重新处理 |
| 已取消 | 取消 | 确认是否已派车 |

---

## 八、常见问题

- **看不到“配车确定订单”按钮？** 非配车单走另一个按钮；非线路角色/已确认也不显示。
- **为什么开通账号要我手机号？** 线路/调度必须填手机号，系统要用来联系司机/客户、记录操作人。
- **订单被驳回？** 看原因，让客户改对应项再提交。
- **这单算我的吗？** 看下单人是不是你这家绑定的会员，或装/卸货地在不在你这家区域内。都不是别轻易确认。
- **确认错了怎么办？** 问管理员（可重新报价/取消/驳回），别自己乱改。

> 本手册依据系统「我的订单」实际界面整理，按钮以订单当前状态为准。
