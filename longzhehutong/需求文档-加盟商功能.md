# 物流系统加盟商功能需求文档

> 版本：V0.1（评审稿） 　 适用范围：longzhehutong 平台（FastAdmin 后端 + 小程序/司机端/专线端） 　 状态：待评审

---

## 1. 背景与目标

平台目前由**总部（总后台）**统一管理调度、线路、财务子账号。现需增加**加盟商**体系，让加盟商也能像总部一样运营，但数据范围只限**自己及下级加盟商**。

目标：

1. 总部可创建**一级加盟商**；一级加盟商可发展**二级加盟商**（最多两级）。
2. 加盟商有独立后台，可管理自己的线路、调度、财务，且与总部共用同一套后台系统（仅角色组不同）。
3. 加盟商可绑定会员、修改会员身份/到期时间，但不能看到全网会员，只能通过**手机号搜索**到已注册会员后绑定。
4. 加盟商有**线上钱包**，线下收款后由上级在线充入；钱包余额用于各项扣费。
5. 完善的扣费规则与“余额不足即禁止操作”的风控。

---

## 2. 角色与权限

| 角色 | 说明 | 主要能力 |
|------|------|----------|
| 总部（超级管理员） | 平台拥有者 | 创建/停用一级或二级加盟商；调整一级钱包余额；设置一级费率；调会员身份/到期（不扣费） |
| 一级加盟商 | 由总部创建 | 类似总后台的后台；管理自己的线路/调度/财务；创建二级加盟商；调整二级钱包余额；设置二级费率；搜会员并绑定、改身份/到期（扣费） |
| 二级加盟商 | 由一级创建 | 类似总后台的后台；管理自己的线路/调度/财务；查看/管理自己钱包；搜会员并绑定、改身份/到期（扣费）；不能再发展下级 |
| 绑定会员 | 平台注册用户 | 被加盟商绑定后，其订单归属该加盟商；会员不直接操作加盟商后台 |

> 加盟商登录沿用现有后台（admin）账号体系，仅分配不同角色组；数据范围通过角色组树 + 会员绑定自动隔离。

## 3. 功能需求

### 3.1 加盟商管理

- 总部在后台“加盟商管理”中可：新建一级加盟商（填写名称/联系人/电话，并为其创建登录管理员账号 + 角色组）；也可为某个一级加盟商下新建二级加盟商；编辑资料、停用/启用；查看列表（含钱包余额、上级、状态）。
- 一级加盟商只能看到自己及名下二级加盟商；只能新增二级加盟商（上级固定为自己）；可编辑自己名下二级加盟商的资料与费率、调整其钱包。
- 二级加盟商只能查看/管理自己；无法新增下级。

### 3.2 加盟商后台（类似总后台）

- 加盟商拥有与总后台一致的线路、调度、财务等模块，但只能看到自己及下级加盟商的数据。
- 加盟商后台能看到的菜单，由框架自带的**角色组权限点选**（在“角色组”中勾选）决定，总部为加盟商建组时按需勾选；默认不勾选系统管理、权限、通用配置等后台管理项。

### 3.3 会员绑定与身份/到期修改

- 加盟商不能看到所有会员，也不能在会员列表直接新增会员。
- 加盟商通过手机号搜索会员：若已注册则展示其用户名/手机号/身份/职位/到期时间，并可绑定到本人名下；若未注册则提示“需先在平台注册”。
- 绑定成功后，下次无需搜索即可在“会员管理/我的会员”中查看该会员。
- 加盟商可修改已绑定会员的以下字段：username（用户名称）、membertype（职位）、member_time（会员到期时间）。
- 总部（超管）也可修改任意会员的这些字段，但不扣费。
- 会员一旦被某加盟商绑定，其他加盟商不得重复绑定。

### 3.4 钱包管理

- 每家加盟商有一个线上钱包（余额）。
- 一级加盟商线下向总部缴费，由总部在线为其钱包充值/调整余额。
- 二级加盟商线下向一级加盟商缴费，由一级加盟商在线为其钱包充值/调整余额。
- **一级加盟商不能给自己充值**，只能由总部给一级充值；一级只能给其名下二级充值。
- 钱包流水记录每次变动（收入/支出、变动前后余额、关联订单/会员/加盟商、操作人、时间）。

### 3.5 扣费规则

#### 3.5.1 修改会员身份/到期

- 触发扣费的条件：修改了 `membertime`（会员到期时间）或 `membertype`（职位）；**仅修改 `username`（用户名称）不扣费**。
- **例外（免费）**：仅当把会员设为“正式员工”（内部员工）时免费（计入正式员工名额）；设为“普通/兼职”或修改到期时间仍扣费。
- 月数计算：按月数 = ceil((新到期时间 − 当前时间) / 30 天)；不足一个月的按一个月（至少 1 个月）。
- 扣费金额 = 月数 × 单价，从该加盟商钱包扣除。
- 单价默认 150 元/月，**由总部统一调整**（一级与二级使用同一标准，不各自设置）。
- **内部员工免费开通账号**（设为正式员工）**不扣费**；该免费操作受 3.8 的正式员工名额限制。

#### 3.5.2 新增二级加盟商

- 由一级加盟商操作，从一级加盟商钱包扣除新增二级单价（默认 500 元，总部可设置）。
- 该 500 元单价同样**由总部统一调整**。

#### 3.5.3 订单扣费

- 扣费基数 = `pay_price`（用户支付金额/总运费）。
- 扣费在订单完成时发生：
  - 送货司机完成订单（dricerorder.type=3）时触发。
  - 另外后台“确认收货/专车到达”时也触发（兼容无送货司机的订单）。
- 规则：
  - 会员归属一级加盟商：扣该一级加盟商钱包 总运费 × 比例（默认 1%，总部可改）。
  - 会员归属二级加盟商：扣该二级加盟商钱包 总运费 × 比例（默认 1.5%，一级可改）；同时扣其上级一级加盟商钱包 总运费 × 比例（默认 1%，总部可改）。
- 同一订单对同一加盟商只扣一次（按订单号判重）。

### 3.6 余额不足/操作阻断

- 任一加盟商（含其上级）钱包余额 ≤ 0 时，该加盟商及其所有下级账号禁止操作（绑定会员、改会员、新增二级、订单完成扣费等相关操作）。
- 余额不足、无权限、重复绑定等边界情况，一律禁止并给出明确提示。

### 3.7 加盟商区域与订单可见/抢单范围

- 每个加盟商有自己的**区域**，区域粒度按层级区分：
  - **一级加盟商**：区域为**“市”**，可多选（如：德州、聊城）。
  - **二级加盟商**：区域为**“区/县”**，**必须位于其上级（一级）加盟商所选城市的区划范围内**（例如一级选了德州，二级只能在德州下辖的区/县中选择）。
- 总部可设置一级加盟商区域；一级可设置其名下二级加盟商区域。
- “**普通用户**”定义：**未绑定任何加盟商**的会员。
- 可见/抢单规则（**除总后台外**）：
  - **加盟商管理员账号**：可见 **自己 + 所有下级加盟商**（含二级）的订单/会员。
  - **该加盟商的调度/线路账号**：仅可见 **该加盟商自己绑定的正式/兼职员工（及普通用户）的订单** ＋ **该加盟商区域内“未绑定普通用户”的订单**；**不可见下级加盟商**的订单。
- 未绑定普通用户的订单归属：按“**最深匹配区域**”归属 —— 命中二级区/县则归二级；否则命中一级所在市则归一级。
- 其他加盟商及其调度/线路**不能**看到或抢到这些订单。
- 实现上：加盟商作为“代理(identity=1)”角色组（区域写入其 `city`，绑定会员写入现有 `admin_user_bind`）；调度/线路子账号向上取“最近一级代理组”即可获得区域内未绑定用户 + 本组绑定会员的范围，而不会越级看到下级加盟商数据。

### 3.8 内部员工免费开通账号与正式员工名额

- 加盟商可**免费开通（免费调整为正式员工）**：把**已在平台注册的会员**直接设为**正式员工**，用于自己**内部员工**使用（不扣会员费）。
- 内部员工使用**小程序**登录（复用现有会员端，无需新建登录端）。
- 会员身份分为：**普通用户、正式员工、兼职员工**（保留现有：普通/兼职/正式/会展）。
  - **外来人员**（非内部员工）注册/调整时，设为 **兼职员工**；
  - **自己的内部员工**，设为 **正式员工**。
- **正式员工名额**：名额 = 该加盟商绑定会员中“正式员工”数量。总部为一级设置名额上限，一级为其名下二级设置名额上限；达到上限后不能再新增正式员工。
- 免费开通仅指“把内部员工设为正式员工”；**把外来用户调成兼职员工仍按“改会员 150 元/月”扣费**。

### 3.9 兼职身份抽成

- 兼职员工的**抽成逻辑已存在**（基数用 `pay_price`），**无需新增抽成计算逻辑**。
- 只需确保**加盟商能修改自己绑定用户的抽成百分比**（后台已有该百分比入口，开放给加盟商即可）。

### 3.10 统计与报表（数据可见范围）

- **统计/报表的数据范围与列表一致**：凡是列表能看到的，统计也要能算到；统一按“当前登录人可见范围”过滤，避免出现“看得到单、统计却遗漏”。
- **总后台（超管）**：看**所有加盟商**的全部数据与汇总——会员、订单、财务、加盟商、抽成/提成、区域分布；支持按加盟商/层级/区域/时间/订单状态等维度筛选取数与下钻。
- **一级加盟商管理员**：看**自己 + 名下所有二级加盟商**的会员/订单/财务/加盟商与汇总统计（不含其他一级及各无关加盟商数据）。
- **二级加盟商管理员**：只看**自己**的数据与统计。
- **加盟商的线路/调度子账号**：只看**其所属加盟商范围内**的数据统计（该加盟商绑定会员 + 区域内未绑定普通用户）。
- 主要统计维度（同一套指标、只是范围不同）：
  - **会员**：总量 / 已绑定 / 未绑定 / 普通 / 兼职 / 正式员工、区域分布。
  - **订单**：单量 / 总运费(pay_price) 合计 / 各状态（进行中/已完成/取消/驳回） / 区域 / 车型 / 找车类型。
  - **财务**：钱包余额 / 收支配比 / 各扣费明细（改会员、新增二级、订单完成扣费）/ 充值流水 / 提现。
  - **调度备用金**：`finance/reserve_fund`（线路/调度备用金）+ `finance/reserve_fund_log`（备用金流水）；备用金按“调度/线路管理员账号”开户。
    - **加盟商管理员**：可为**自己名下的调度/线路账号**充值备用金；充值通过现有「线路/调度备用金 `finance/reserve_fund`」页面进行（直接入账，不与加盟商钱包联动；**加盟商管理模块不提供备用金充值按钮**）。
    - **加盟商的调度/线路账号**：可见、充值**自己账号**的备用金。
    - 数据范围按 `franchise_id` 子树隔离（总后台看全部，一/二级只看到自己及下级的备用金）。
  - **加盟商**：数量（一级/二级）、层级结构、区域覆盖、正式员工名额使用。
  - **抽成/提成**：兼职抽成、管理员提成（复用现有逻辑）。
  - **工作数据**：线路/调度/财务子账号处理单量、抢单情况。
- **权限驱动方式**：超管与各家加盟商看到的是同一套指标与页面，只是底层的 `franchise_id`（及区域/绑定）过滤范围不同。

## 5. 数据隔离与权限

- 加盟商作为登录后台的管理员，放入对应角色组树：一级=总部下的一棵“代理(identity=1)”组；二级=一级下面的“代理”组。
- 订单/会员的可见性遵循 **3.7 区域 + 绑定会员** 规则：
  - **加盟商管理员**：自己 + 所有下级加盟商（含二级）的订单/会员。
  - **加盟商的调度/线路账号**：自己所处的这家加盟商“绑定的正式/兼职员工订单 + 区域内未绑定普通用户订单”；不跨到下级加盟商。
- **统计/报表**同样遵循上述范围（见 3.10）：总后台=全部加盟商；一级=自己+所有二级；二级=自己；子账号=其所属加盟商范围。
- 实现上：区域写入加盟商角色组 `city`，绑定会员写入现有 `admin_user_bind`；调度/线路按“最近一级代理组”取范围，加盟商管理员按“整棵加盟商子树”取范围。

## 6. 主要业务流程（验收走查）

1. 总部「加盟商管理→新增」创建一级加盟商 A（自动创建登录账号、角色组、档案）。
2. 总部为 A 设置**区域**（如：德州、聊城），并「调整钱包」给 A 充值（线下收款后加余额）。
3. A 登录后台，绑定会员 M（按手机号搜索→绑定），改 M 身份/到期 → 从 A 钱包扣 月数×150（仅改 username 不扣费）。
4. A 「加盟商管理→新增」创建二级加盟商 B（设置 B 区域）→ 从 A 钱包扣 500。
5. A 「调整钱包」给 B 充值（一级给二级加余额；一级不能给自己充值）。
6. B 登录后台，绑定会员 N、改身份/到期 → 从 B 钱包扣 月数×150。
7. **可见/抢单**：区域内普通用户订单、以及 A 名下绑定会员 M 的订单，只有 A 体系（A 自己 + 名下调度/线路）及总后台可见、可抢。
8. 订单完成时：若 M 的订单属于 A，A 扣 pay_price×1%；若 N 的订单属于 B，则 B 扣 pay_price×1.5% 且 A 扣 pay_price×1%。
9. 当 A 钱包余额 ≤ 0：A 及其下级（B、其名下会员）相关操作全部被阻断并提示。

## 7. 待确认问题（请评审时反馈）

### 7.1 已确认（按你的答复）

1. 仅改用户名（username）不扣费；仅当改到期/职位时扣费。
2. 月数 = ceil((新到期时间 − 当前时间) / 30 天)，不足 1 个月按 1 个月。
3. 订单扣费基数 = `pay_price`。
4. 余额不足 → 阻断并提示（司机完成订单也会因此失败）。
5. 一级加盟商能看到二级加盟商的全部数据（自己 + 下级）。
6. 一级加盟商不能给自己充值（总部给一级充、一级给二级充）。
7. 加盟商后台菜单范围：由框架自带的“角色组”权限点选（在 角色组 中勾选）。
8. 内部员工免费开通 = 把已注册会员直接设为正式员工（不需要新建登录账号），内部员工用小程序登录。
9. 正式员工名额 = 该加盟商绑定会员中“正式员工”数量；上限由总部给一级设、一级给二级设。
10. 兼职抽成逻辑已存在（基数 pay_price），只需让加盟商能改自己绑定用户的“抽成百分比”。
11. 外来用户调成兼职员工仍按“改会员 150 元/月”扣费；仅“内部员工设为正式员工”免费。
12. 改会员(150)、新增二级(500) 采用**全加盟商共用一个全局值**，由总部统一设置。
13. 调度备用金：加盟商管理员给自己名下的调度/线路账号充值，走现有 `finance/reserve_fund` 页面（直接入账，不与加盟商钱包联动）；**加盟商管理模块不设备用金充值按钮**；数据按加盟商子树隔离。

## 8. 验收标准（草案）

- 总部可创建一级加盟商；一级可创建二级加盟商（二级无法再创建下级）。
- 一级加盟商区域为“市”（可多选）；二级加盟商区域只能选其上级所选城市的“区/县”；未绑定普通用户订单按“最深匹配区域”归属（区县优先、再市）。
- 加盟商后台数据严格限制在“自己 + 下级”，无法看到其他加盟商数据。
- 加盟商只能按手机号搜索已注册会员，绑定后可改 username/membertype/member_time，并从钱包按规则扣费。
- 二级加盟商新增时，一级钱包扣 500；改会员按月扣 150（可配置）；订单完成按比例扣费。
- 任一加盟商余额 ≤ 0 时，其及下级账号的操作被阻断并给出提示。
- 钱包流水完整、可追溯；订单扣费每个订单只扣一次。
- 区域内普通用户订单、以及加盟商已绑会员的订单，除总后台外仅该加盟商体系（自己 + 名下调度/线路）可见、可抢；其他加盟商看不到、抢不到。
- 加盟商可把已注册会员“免费设为正式员工”并受名额限制；外来用户调成兼职员工按“150 元/月”扣费。
- 加盟商可修改自己绑定用户的“抽成百分比”（兼职抽成）。
- 统计/报表按角色可见范围隔离：总后台看全部加盟商；一级看自己+名下二级；二级只看自己；子账号只看其所属加盟商范围。
