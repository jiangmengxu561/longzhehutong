# 加盟商后台操作手册（零基础入门版）

> 适用对象：新加入的一级 / 二级加盟商，以及刚拿到后台账号、还没用过系统的人。
> 一句话说明：你登录的这套后台，是**总部系统的加盟商版**。界面和总部一样，但你的账号只能看到**你自己（和你发展的下级）**的数据和订单。

---

## 一、先认识这套系统的分工

整个平台由几块组成，你主要打交道的是「**后台**」：

| 系统 | 谁在用 | 干什么 |
|------|--------|--------|
| 总部后台 | 平台总部 | 建加盟商、设费用、给一级加盟商充钱包、看全网数据 |
| **加盟商后台**（你） | 你 + 你的员工 | 管理自己的会员和订单、配车派单、记账 |
| 客户端小程序 | 你的客户（会员） | 下单、查物流 |
| 司机端 | 司机 | 接单、装货、在途、卸货、确认完成 |
| 专线端 | 专线物流 | 专线承运、专车到达 |

后台**左上方登录的账号**决定了你能看到什么：

- **一级加盟商**：看到自己 + 自己名下所有二级加盟商的数据。
- **二级加盟商**：只看到自己。
- **加盟商下面的线路 / 调度 / 财务账号**：只看**这家加盟商**自己的业务，看不到下级加盟商。

## 二、首次登录后台（第 1 天必做）

1. 打开后台登录页，用**总部给你开的账号**（用户名 / 密码）登录。
2. 登录后**第一件事：改密码**。右上角「个人中心/reset密码」，设置一个只有你知道的密码。
3. 认识一下左侧菜单。加盟商默认常用的菜单主要有：
   - **首页**：看当天概要、提醒。
   - **会员管理**：绑定和管理你的客户（会员）。
   - **订单管理**：看订单、派单、确认完成。
   - **物流/专线**：专线相关操作。
   - **财务记账**：收支记录。
   - **财务**：钱包、抽佣、报表。
   - **加盟商管理**：如果你是总部或一级，这里可以发展下级、调下级钱包。

> 如果某个菜单没看到，别慌——说明你的账号角色「权限」里没勾这个菜单，找总部（或你的上级一级加盟商）开通即可。

## 三、最核心的三个概念：钱包、会员、订单

### 3.1 钱包（你的“余额账户”）

- 每家加盟商有一个**线上钱包**，余额就是你的可用资金。
- **钱从哪来**：线下把钱交给上级 → 上级在后台给你**充值**到钱包。
  - 一级加盟商 → 由**总部**充值。
  - 二级加盟商 → 由**上级一级**充值。
  - **一级不能给自己充值**，只能给下级的二级加盟商充值。
- **钱什么时候花**：改会员身份/到期、新增二级加盟商、订单完成抽佣、每月的加盟月费，都会从钱包里扣。
- **重要规则：钱包余额 ≤ 0 时，你（以及你名下的下级、员工）将**不能操作**（不能绑会员、不能改会员、不能新增下级等）。所以**先充钱再干活**。

> 看余额/看流水：左侧「加盟商管理」→ 找到自己那行 → 点「钱包」，能看到每一次**充值 / 扣费 / 余额变化**。

### 3.2 会员（你的客户）

- 会员是**在平台上注册过的用户**（通过在客户端小程序注册得到）。
- 你要让某个客户**算成你的**，就**把它“绑定”到自己名下**。绑定后，这个客户的订单就归你，你才能看到和处理。
- 会员有几种身份：

| 身份 | 说明 | 收费 |
|------|------|------|
| 普通用户 | 普通客户 | 绑定时不收费 |
| 兼职员工 | 外部的、兼职性质 | 设为兼职或改到期要**按月扣费** |
| 正式员工 | 你自己的内部员工 | **免费**（占用一个“正式员工名额”） |
| 会展员工 | 会展性质 | 按月扣费 |

### 3.3 订单（你的生意）

- 客户在小程序下单后，订单进入系统。
- 如果一个订单的客户**已经绑定为你的会员**，这个订单**自动归你**。
- 如果一个订单是**没有绑定任何加盟商的“普通用户”**下的，系统会按**装/卸货地址所在区域**，把订单归到**最匹配**的加盟商：先看区/县（二级），再细到市（一级）。也就是说，**你选的区域越大、越准，能落到你手里的“无主订单”越多**。
- 不属于你的订单，你**看不到、也抢不到**。

## 四、日常操作全流程（按顺序看）

这是一天里你做的最常见的四件事，顺序养成习惯：

1. **查看钱包**，确认余额够用（钱不够先去充）。
2. **绑定会员**（把新客户归自己名下；内部员工设成免费正式员工）。
3. **处理订单**（有单来了：分线路 → 配车 → 派司机 → 跟踪 → 确认完成）。
4. **记账 / 看报表**（核对收入、确认抽佣、算利润）。

## 五、一个订单进来后：第一步、第二步、第三步……

这是本手册最重要的一节。下面按「订单从客户下单，到最终完成扣费」的完整链条讲。

### 第 1 步：订单进来了，先确认“是不是你的单”

- 打开**「订单管理」**（或线路/调度用的**「我的订单」**）。
- 新订单会有**语音提醒 / 红点 / 待处理提示**。
- 先看这一单：
  - **下单人**是不是你绑定的会员？
  - **装货地、卸货地**是不是在你选的区域内？
  - 如果都不是，这单可能不属于你，不用处理。

### 第 2 步：核对订单信息

点开订单详情，确认几件事，错了马上联系客户改：

- **装货 / 卸货地址、联系人和电话**
- **货物**（品名、重量、体积、车型要求、包装）
- **价格 / 运费**（`pay_price` 总运费，这是之后抽佣的基数）
- **时效要求**（最早/最晚装货、到货时间）
- **找车类型**（配车 / 专车 / 小票快运）和**支付方式**（是否在线支付、是否已付款）

> 信息不全或地址写错的单，先别往下派，联系客户补齐。

### 第 3 步：派单给线路（或你自己接）

通常流程是「**线路**接单 → **调度**配车」：

- **线路（销售/规划角色）**：在「我的订单」看到单后**抢单/确认**，订单进入**线路已确认**状态（后台标记 `backend_status=1`）。
- 如果你的加盟商较小、没有专门的线路/调度账号，就由你（管理员）统一处理。

### 第 4 步：调度配车（安排车和司机）

- **调度员**从「我的订单」看到「线路已确认、待配车」的单。
- 进入**配车**：选择合适的**车辆**和**司机**，指派给司机。
- 配好车后订单进入**调度已确认**状态（`backend_status=2`）。
- 司机通过**司机端**收到任务，开始装货、运输。

### 第 5 步：跟踪运输过程

- 在订单/物流里看**轨迹**：装货、在途、卸货各环节。
- 司机在司机端会更新状态，你可以在后台「物流轨迹」页面随时查看。
- 有异常（晚点、地址变化、司机联系不上）及时处理。

### 第 6 步：确认完成（关键一步，关系到你钱包扣费）

订单会在两条链路之一**被标记完成**：

- **司机端**：送货司机完成订单（司机端操作，`dricerorder.type=3`）。
- **后台**：管理员在后台做「**确认收货 / 专车到达**」（物流状态 `logistics_status=7`），适用于没有送货司机的单（如纯专线单）。

> 这一下**系统会自动从你钱包扣相应抽佣**（见第七节扣费规则）。所以别漏确认，也别乱确认。

### 第 7 步：订单完成后的账务

- 订单完成后，系统按**总运费 × 比例**从你的钱包扣**订单抽佣**。
  - 一级加盟商：按 `1%`（总部可调整）。
  - 二级加盟商：按 `1.5%`（一级可调整），同时它的上级一级加盟商再抽 `1%`（总部可调整）。
- 同一订单对同一加盟商**只会扣一次**，不用担心重复扣。
- 你可以在「**加盟商管理 → 钱包 / 抽佣明细**」里看每单扣了多少钱。

### 第 8 步：记账与对账（可选但建议）

- 在「**财务记账**」里记录收支（成本、司机费用、杂费）。
- 在「**财务**」看钱包余额、抽佣、利润。
- 在「**加盟商管理 → 抽佣明细**」核对每单抽佣金额。

### 常见订单状态对照表

| 状态 | 含义 | 你要做什么 |
|------|------|-----------|
| 待付款 | 客户还没付款 | 确认是否线下已收，或催付 |
| 待下单 | 客户提交了但还没正式下单 | 联系客户确认，或忽略 |
| 进行中 / 服务中 | 已派单，运输中 | 跟进在途 |
| 已完成 | 司机/后台已确认完成 | 对账、看抽佣 |
| 已取消 | 客户或后台取消 | 如果已派车，确认是否有损失 |
| 驳回 | 后台驳回 | 看驳回原因，修改后重新提交 |

## 六、具体功能怎么操作

### 6.1 给二级加盟商/自己充钱包（充值/调整钱包）

- 入口：**「加盟商管理」→ 对应加盟商那一行 →「调钱包」**。
- 选择**方向**：
  - `充值（收入）`：线下收到钱，线上加余额。
  - `扣减（支出）`：线下退款，线上减余额。
- 填**金额**和**备注**（如“线下转账充值”），点确定。
- 之后在「**钱包**」里能看到这条流水。

> 谁给谁充：总部给一级充；一级给它的二级充。一级不能给自己充。

### 6.2 绑定会员（把客户归到自己名下）

1. 进「**加盟商管理 → 会员**」（或「会员管理」）。
2. 点「**按手机号绑定会员**」。
3. 输入客户**手机号**，点搜索。
   - 若已注册 → 显示用户名/手机号/身份/到期，点「**绑定到我的名下**」。
   - 若未注册 → 提示“需先在平台注册”，让客户去小程序先注册。
4. 绑定成功后，以后在「会员」列表就能直接看到这个客户，不用再搜。

> 注意：会员**只能被一家加盟商绑定**。一旦归到你名下，别的加盟商不能再绑。

### 6.3 修改会员身份 / 到期时间（会扣费）

1. 在「**会员**」列表找到该会员，点「**改身份/到期**」。
2. 可修改：
   - **用户名称**：改名字**不扣费**。
   - **身份/职位**：普通 / 兼职 / 正式 / 会展。
   - **到期时间**：选到期日期。
   - **平台抽佣%**：这个会员的兼职抽成比例（你按自己的政策填）。
3. 点确定。系统会**按规则自动扣费**：
   - **设为“正式员工”**：免费（占用一个正式员工名额）。
   - **其余（设为兼职/普通/会展，或改到期时间）**：按 `月数 × 150元/月` 扣费，不足一个月按一个月算。

> 正式员工名额：`加盟商管理 → 编辑`里能看到上限。名额用完了，就不能再免费设正式员工。

### 6.4 管理员工账号（线路 / 调度 / 财务）

- 入口：**「加盟商管理 → 员工」→「添加员工」**。
- 三种角色：
  - **线路**：接单、确认订单（销售性质）。
  - **调度**：配车、派司机。
  - **财务**：记账、对账。
- 填**登录账号、登录密码、姓名、手机号**（线路/调度必须填手机号）。
- 可对已有员工**停用 / 启用 / 删除**。

> 给子账号分配“能看到什么”由**角色组权限**控制，找总部/上级在「角色组」里勾选即可，默认只给订单/调度/财务/会员相关菜单，不建议给系统管理权限。

### 6.5 发展下级加盟商（仅总部或一级）

- 总部 → 新建**一级加盟商**；一级 → 新建它的**二级加盟商**。
- 新建时填：名称、联系人、电话、**区域**（一级选“市”可多选、二级只选“区/县”且必须属于上级所选的市）、**正式员工名额**等。
- 新建二级会**自动从你这个一级的钱包扣 `500元`**（总部可设置这个标准）。
- 二级加盟商**不能再发展下级**。

### 6.6 全局费用设置（仅总部）

- 入口：**「加盟商管理 → 全局设置」**。
- 可设置：
  - **改会员月费**（默认 150 元/月，全加盟商共用）。
  - **新增二级扣费**（默认 500 元，全加盟商共用）。
  - **加盟商月费**（默认 1000 元/月，每月自动从正常加盟商钱包扣，设为 0 则不扣）。
  - **规则模板加盟商**：新加盟商按哪个模板的菜单/权限自动生成。

## 七、扣费规则速查表

| 场景 | 从谁钱包扣 | 扣多少钱 | 备注 |
|------|-----------|---------|------|
| 修改会员身份/到期 | 该会员所属加盟商 | 月数 × 150 元/月 | 仅改“名称”不扣；设为正式员工免费 |
| 新增一个二级加盟商 | 发起的一级加盟商 | 500 元 | 总部统一设 |
| 月度加盟费 | 每个正常加盟商 | 1000 元/月 | 每月自动扣，创建当月不扣 |
| 订单完成（一级会员） | 该一级加盟商 | 总运费 × 1% | 总部可调整 |
| 订单完成（二级会员） | 二级 + 其上级一级 | 二级 × 1.5% + 一级 × 1% | 一级可调二级比例，总部可调一级比例 |
| 钱包不足 | — | 一律禁止操作并提示 | 任一加盟商余额 ≤0，其名下及下级都不能操作 |

> 这里的比例（1% / 1.5%）和金额（150 / 500 / 1000）是**默认值**，实际以总部/上级在后台设置为准。

## 八、常见问题 FAQ

**Q：我点绑定会员/改会员/新增下级，提示“不允许操作/余额不足”？**
A：你的钱包（或你的上级钱包）余额 ≤ 0，系统按风控**禁止操作**。先找上级充值，再操作。

**Q：我搜不到这个会员？**
A：这个手机号还没在平台注册。让客户先到小程序注册，再来搜。

**Q：为什么我能看到这单？**
A：要么下单客户是你绑定的会员，要么这单的装/卸货地在你选的区域内（未绑定普通户订单）。

**Q：订单完成了，为什么就扣了我钱包的钱？**
A：这是**订单完成抽佣**，按总运费 × 比例扣。可在「抽佣明细」里核对每一单。

**Q：为什么我没有“加盟商管理/全局设置”菜单？**
A：这些是总部/一级才有权限的操作。你没有说明你的角色不开放，找上级开通或由上级代操作。

**Q：司机端完成后我还要再点“确认收货”吗？**
A：司机完成的单一般自动完成；如果是**纯专线、没有送货司机**的单，需要在后台点「**确认收货/专车到达**」来标记完成（同时会触发扣费）。

## 九、给你的“上手清单”

拿到账号后的头几天，按这个清单走一遍，基本就上手了：

1. [ ] 登录，改密码。
2. [ ] 确认自己钱包余额，不足找上级充值。
3. [ ] 检查自己选的**区域**是否覆盖你想要的范围。
4. [ ] 绑定第一批会员（自己的老客户、内部员工）。
5. [ ] 给员工开好线路/调度/财务账号，分好权限。
6. [ ] 试一单：下单 → 看单 → 派线路 → 配车 → 派司机 → 司机完成/后台确认。
7. [ ] 到「抽佣明细 / 钱包流水」核对扣费是否正常。
