# 组件说明文档

## 概述

本文档说明项目中使用的 UI 组件库和自定义组件，帮助开发者了解各组件的使用方法和配置。

## UI 组件库

### 1. uni-ui

uni-app 官方 UI 组件库，提供基础组件。

**官方文档**: [uni-ui 组件库](https://uniapp.dcloud.net.cn/component/uniui/uni-ui.html)

**已使用组件**:
- `uni-popup`: 弹窗组件
- `uni-transition`: 过渡动画组件

### 2. uv-ui

基于 uView 2.x 改进的 uni-app UI 组件库，全面支持 Vue 3。

**官方文档**: [uv-ui 组件库](https://www.uvui.cn/components/intro.html)

**已使用组件**:
- `uv-icon`: 图标组件
- `uv-popup`: 弹窗组件
- `uv-picker`: 选择器组件
- `uv-loading-icon`: 加载图标
- `uv-safe-bottom`: 安全区域底部
- `uv-status-bar`: 状态栏
- `uv-toolbar`: 工具栏
- `uv-transition`: 过渡动画
- `uv-overlay`: 遮罩层

**工具库**: `uv-ui-tools`
- HTTP 请求封装
- 便捷工具函数
- 节流防抖
- 对象操作
- 时间格式化
- 路由跳转
- 规则校验

### 3. lime-ui

轻量级 uni-app UI 组件库。

**已使用组件**:
- `lime-picker`: 选择器组件
- `lime-loading`: 加载组件
- `lime-color`: 颜色工具
- `lime-style`: 样式工具

**工具库**: `lime-shared`
- 获取节点尺寸信息
- 单位转换
- Canvas 2D 支持检测
- Base64 图片转换
- 节流防抖
- 数值计算工具
- 字符串工具

### 4. 第三方组件

#### xzw-notice (公告组件)

**位置**: `uni_modules/xzw-notice`

**功能**: 滚动公告展示

**使用示例**:
```vue
<template>
  <xzw-notice 
    :showIcon="false" 
    :showMore="false" 
    :list="noticeList" 
  />
</template>

<script>
export default {
  data() {
    return {
      noticeList: [
        { title: '公告标题1', content: '公告内容1' },
        { title: '公告标题2', content: '公告内容2' }
      ]
    }
  }
}
</script>
```

**Props**:
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| list | Array | [] | 公告列表 |
| showIcon | Boolean | true | 是否显示图标 |
| showMore | Boolean | true | 是否显示更多按钮 |

#### zfl-logistics (物流轨迹组件)

**位置**: `uni_modules/zfl-logistics`

**功能**: 显示物流轨迹、时间线、步骤条

**使用示例**:
```vue
<template>
  <zfl-logistics :list="trackList" />
</template>

<script>
export default {
  data() {
    return {
      trackList: [
        { time: '2024-01-01 10:00:00', status: '订单已创建', location: '北京市' },
        { time: '2024-01-01 11:00:00', status: '司机已接单', location: '北京市' }
      ]
    }
  }
}
</script>
```

## 常用组件使用

### 1. 弹窗组件 (uni-popup)

```vue
<template>
  <uni-popup ref="popup" type="center">
    <view class="popup-content">
      <text>弹窗内容</text>
    </view>
  </uni-popup>
</template>

<script>
export default {
  methods: {
    showPopup() {
      this.$refs.popup.open()
    },
    hidePopup() {
      this.$refs.popup.close()
    }
  }
}
</script>
```

### 2. 选择器组件 (picker)

```vue
<template>
  <picker 
    mode="selector" 
    :range="options" 
    :value="selectedIndex"
    @change="onPickerChange"
  >
    <view class="picker-view">
      <text>{{ options[selectedIndex] }}</text>
    </view>
  </picker>
</template>

<script>
export default {
  data() {
    return {
      options: ['选项1', '选项2', '选项3'],
      selectedIndex: 0
    }
  },
  methods: {
    onPickerChange(e) {
      this.selectedIndex = e.detail.value
    }
  }
}
</script>
```

### 3. 轮播图组件 (swiper)

```vue
<template>
  <swiper 
    class="banner-swiper" 
    :autoplay="true" 
    :interval="3000" 
    :duration="1000"
    circular
  >
    <swiper-item v-for="(item, index) in bannerList" :key="index">
      <image :src="item" mode="aspectFill" />
    </swiper-item>
  </swiper>
</template>

<script>
export default {
  data() {
    return {
      bannerList: [
        '/static/images/banner1.jpg',
        '/static/images/banner2.jpg'
      ]
    }
  }
}
</script>
```

### 4. 加载组件

```vue
<template>
  <view>
    <!-- 使用 uni.showLoading -->
    <button @click="showLoading">显示加载</button>
  </view>
</template>

<script>
export default {
  methods: {
    showLoading() {
      uni.showLoading({
        title: '加载中...',
        mask: true
      })
      
      // 模拟请求
      setTimeout(() => {
        uni.hideLoading()
      }, 2000)
    }
  }
}
</script>
```

## 组件开发规范

### 1. 组件命名

- 组件文件名使用 PascalCase，如 `OrderCard.vue`
- 组件注册名使用 kebab-case，如 `<order-card>`

### 2. 组件结构

```vue
<template>
  <!-- 模板 -->
</template>

<script>
export default {
  name: 'ComponentName',
  props: {
    // Props 定义
  },
  data() {
    return {
      // 数据
    }
  },
  methods: {
    // 方法
  }
}
</script>

<style scoped>
/* 样式 */
</style>
```

### 3. Props 定义

```javascript
props: {
  // 基础类型
  title: {
    type: String,
    default: ''
  },
  // 数字类型
  count: {
    type: Number,
    default: 0
  },
  // 布尔类型
  show: {
    type: Boolean,
    default: false
  },
  // 数组类型
  list: {
    type: Array,
    default: () => []
  },
  // 对象类型
  config: {
    type: Object,
    default: () => ({})
  }
}
```

### 4. 事件定义

```javascript
// 触发事件
this.$emit('change', value)

// 在父组件中监听
// <component @change="handleChange" />
```

### 5. 插槽使用

```vue
<!-- 组件定义 -->
<template>
  <view class="component">
    <slot name="header"></slot>
    <slot></slot>
    <slot name="footer"></slot>
  </view>
</template>

<!-- 组件使用 -->
<component>
  <template #header>头部内容</template>
  <view>默认内容</view>
  <template #footer>底部内容</template>
</component>
```

## 组件通信

### 1. 父子组件通信

**父传子 (Props)**:
```vue
<!-- 父组件 -->
<child-component :title="title" :count="count" />

<!-- 子组件 -->
<script>
export default {
  props: {
    title: String,
    count: Number
  }
}
</script>
```

**子传父 (Events)**:
```vue
<!-- 子组件 -->
<button @click="handleClick">点击</button>

<script>
export default {
  methods: {
    handleClick() {
      this.$emit('change', '新值')
    }
  }
}
</script>

<!-- 父组件 -->
<child-component @change="handleChange" />
```

### 2. 跨组件通信

**使用 EventBus**:
```javascript
// 创建 EventBus
// utils/eventBus.js
import Vue from 'vue'
export default new Vue()

// 发送事件
import eventBus from '@/utils/eventBus'
eventBus.$emit('event-name', data)

// 监听事件
eventBus.$on('event-name', (data) => {
  console.log(data)
})

// 移除监听
eventBus.$off('event-name')
```

**使用 Vuex** (如需要):
```javascript
// store/index.js
import Vue from 'vue'
import Vuex from 'vuex'

Vue.use(Vuex)

export default new Vuex.Store({
  state: {
    count: 0
  },
  mutations: {
    increment(state) {
      state.count++
    }
  }
})
```

## 性能优化

### 1. 组件懒加载

```javascript
// 异步组件
const AsyncComponent = () => import('@/components/AsyncComponent.vue')

export default {
  components: {
    AsyncComponent
  }
}
```

### 2. 使用 v-show 替代 v-if

```vue
<!-- 频繁切换使用 v-show -->
<view v-show="isShow">内容</view>

<!-- 条件很少改变使用 v-if -->
<view v-if="isShow">内容</view>
```

### 3. 列表渲染优化

```vue
<!-- 使用 key -->
<view v-for="item in list" :key="item.id">
  {{ item.name }}
</view>

<!-- 避免在模板中使用复杂计算 -->
<!-- ❌ 不推荐 -->
<view>{{ list.filter(item => item.status === 1).length }}</view>

<!-- ✅ 推荐 -->
<view>{{ activeCount }}</view>

<script>
export default {
  computed: {
    activeCount() {
      return this.list.filter(item => item.status === 1).length
    }
  }
}
</script>
```

## 常见问题

### 1. 组件不显示

- 检查组件是否正确导入
- 检查组件路径是否正确
- 检查组件是否在 `components` 中注册

### 2. 样式不生效

- 检查是否使用了 `scoped`
- 检查样式选择器是否正确
- 检查样式优先级

### 3. 事件不触发

- 检查事件名是否正确
- 检查是否在正确的作用域中
- 检查事件是否被阻止冒泡
