# 开发指南

## 环境准备

### 1. 开发工具

- **HBuilderX**: 推荐使用最新版本的 HBuilderX
- **微信开发者工具**: 用于调试和预览小程序
- **Node.js**: 用于安装依赖（如需要）

### 2. 项目依赖

项目使用 uni-app 框架，主要依赖包括：

- Vue 2.x
- uni-app 核心库
- uni-ui 组件库
- uv-ui 组件库
- lime-ui 组件库

### 3. 微信小程序配置

1. 在微信公众平台注册小程序账号
2. 获取 AppID: `wx1e4884865032dd4f`
3. 在 `manifest.json` 中配置 AppID
4. 配置服务器域名（在微信公众平台后台设置）

## 项目启动

### 1. 导入项目

1. 打开 HBuilderX
2. 文件 -> 导入 -> 从本地目录导入
3. 选择项目根目录 `物流系统小程序`

### 2. 运行项目

1. 在 HBuilderX 中右键项目
2. 选择 "运行" -> "运行到小程序模拟器" -> "微信开发者工具"
3. 首次运行会自动打开微信开发者工具

### 3. 编译项目

1. 在 HBuilderX 中选择 "发行" -> "小程序-微信"
2. 填写版本号和项目名称
3. 点击发行，生成小程序代码包

## 开发规范

### 1. 命名规范

#### 文件命名
- 页面文件: 使用小写字母和连字符，如 `order-detail.vue`
- 组件文件: 使用 PascalCase，如 `OrderCard.vue`
- 工具文件: 使用小写字母，如 `utils.js`

#### 变量命名
- 普通变量: camelCase，如 `userName`
- 常量: UPPER_SNAKE_CASE，如 `API_BASE_URL`
- 组件名: PascalCase，如 `OrderList`

#### 方法命名
- 使用动词开头，camelCase，如 `getUserInfo()`, `submitOrder()`

### 2. 代码风格

#### Vue 组件结构
```vue
<template>
  <!-- 模板内容 -->
</template>

<script>
export default {
  // 组件选项
  data() {
    return {
      // 数据
    }
  },
  onLoad() {
    // 生命周期
  },
  methods: {
    // 方法
  }
}
</script>

<style scoped>
/* 样式 */
</style>
```

#### 代码注释
```javascript
/**
 * 获取订单列表
 * @param {Number} page - 页码
 * @param {Number} limit - 每页数量
 * @returns {Promise} 返回订单列表数据
 */
async getOrderList(page = 1, limit = 10) {
  // 实现代码
}
```

### 3. API 调用规范

#### 统一使用封装的请求方法
```javascript
// ✅ 正确
this.$httpapi('order/list', 'GET', { page: 1 })

// ❌ 错误 - 直接使用 uni.request
uni.request({ ... })
```

#### 错误处理
```javascript
try {
  const res = await this.$httpapi('order/list', 'GET', {})
  if (res.code === 200) {
    // 处理成功
  } else {
    // 处理业务错误
    this.$utils.showtt(res.msg, 'none')
  }
} catch (error) {
  // 处理网络错误
  console.error('请求失败:', error)
}
```

### 4. 样式规范

#### 使用 rpx 单位
```css
/* ✅ 正确 */
.container {
  width: 750rpx;
  padding: 20rpx;
  font-size: 28rpx;
}

/* ❌ 错误 - 使用 px */
.container {
  width: 375px;
}
```

#### 使用 flex 布局
```css
.flex {
  display: flex;
}

.flex-center {
  display: flex;
  align-items: center;
  justify-content: center;
}
```

#### 颜色值管理
建议在 `uni.scss` 中定义全局颜色变量：
```scss
$primary-color: #4878FF;
$text-color: #333333;
$text-gray: #888888;
$bg-color: #F7F6FA;
```

## 常见问题解决

### 1. 页面白屏

**可能原因**:
- 语法错误
- 数据格式错误
- 组件引用错误

**解决方法**:
- 检查控制台错误信息
- 检查页面路径是否正确
- 检查组件是否正确导入

### 2. 接口请求失败

**可能原因**:
- 网络问题
- Token 失效
- 接口地址错误
- 参数格式错误

**解决方法**:
- 检查网络连接
- 检查 Token 是否有效
- 检查接口地址配置
- 检查请求参数格式

### 3. 样式不生效

**可能原因**:
- 样式被覆盖
- 单位使用错误
- 选择器优先级问题

**解决方法**:
- 使用 `scoped` 避免样式污染
- 使用 `!important` 提高优先级
- 检查样式选择器是否正确

### 4. 页面跳转失败

**可能原因**:
- 路径错误
- 页面未在 `pages.json` 中注册
- 跳转方式错误（tabBar 页面需使用 `switchTab`）

**解决方法**:
- 检查路径是否正确
- 检查 `pages.json` 配置
- 使用正确的跳转方法

### 5. 图片不显示

**可能原因**:
- 图片路径错误
- 图片服务器域名未配置
- 图片格式不支持

**解决方法**:
- 检查图片路径（相对路径或绝对路径）
- 在微信公众平台配置图片服务器域名
- 使用支持的图片格式（jpg, png, gif 等）

## 性能优化建议

### 1. 图片优化

- 使用合适的图片格式（WebP 格式更小）
- 压缩图片大小
- 使用懒加载

### 2. 代码优化

- 避免在模板中使用复杂计算，使用计算属性
- 合理使用 `v-if` 和 `v-show`
- 避免频繁的页面跳转

### 3. 数据优化

- 使用分页加载，避免一次性加载大量数据
- 合理使用缓存
- 及时清理不需要的数据

### 4. 网络优化

- 合并请求，减少请求次数
- 使用请求缓存
- 合理设置请求超时时间

## 发布流程

### 1. 代码检查

- 检查是否有语法错误
- 检查是否有未使用的代码
- 检查是否有控制台错误

### 2. 功能测试

- 测试所有功能模块
- 测试不同场景下的使用
- 测试边界情况

### 3. 编译打包

3. 填写版本号和项目备注

1. 登录微信公众平台
2. 进入版本管理
3. 选择上传的版本
4. 填写审核信息
5. 提交审核
